# Swan Therapeutic Services website

Static site: `index.html`, `script.js` (animated flowers), `assets/`.

## Host on GitHub Pages
1. Create a repo and upload the contents of this folder to the root.
2. Settings → Pages → Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
3. The site will be live at `https://<username>.github.io/<repo>/`. For a custom domain, add it under Settings → Pages.
